# JovemTech - Lógica de Programação

Este repositório reúne exercícios práticos de lógica de programação em JavaScript, incluindo:

- listagens de atividades com estruturas condicionais, laços e vetores
- exercícios básicos em HTML/JavaScript
- jogo da memória das cores em terminal
- exemplos de uso de variáveis, operadores e arrays

## Estrutura do projeto

- `atividade.html` — página HTML com funções básicas de JavaScript
- `atividade_1.js` — exercícios de lógica e condicionais
- `atividade_2.js` — laços de repetição (`for`, `while`, `do...while`)
- `atividade_3.js` — vetores e manipulação de dados
- `jogo.js` — jogo da memória das cores no terminal
- `maior_idade.js` — exemplo de cálculo de média e situação do aluno
- `package.json` — configuração básica do projeto Node.js

## Como executar

### HTML
Abra o arquivo `atividade.html` no navegador.

### Scripts Node.js
```bash
node atividade_1.js
node atividade_2.js
node atividade_3.js
node jogo.js
node maior_idade.js
```

## Objetivo

Praticar os conceitos iniciais de programação, lógica, condicionais, laços de repetição, arrays e desenvolvimento de pequenos projetos em JavaScript.
