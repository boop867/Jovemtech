# JovemTech - Lógica de Programação

Este repositório reúne exercícios práticos de lógica de programação em JavaScript e TypeScript, além de pequenos jogos para terminal.

## Conteúdo

### JavaScript
- `atividade.html` — página com funções básicas de JavaScript
- `atividade_1.js` — exercícios de lógica e condicionais
- `atividade_2.js` — laços de repetição (`for`, `while`, `do...while`)
- `atividade_3.js` — vetores e manipulação de dados
- `jogo.js` — jogo da memória das cores no terminal
- `maior_idade.js` — exemplo de média escolar, arrays e condicionais

### TypeScript
- `calculo.ts` — tipos, função de soma e saída no console
- `flappy.ts` — jogo inspirado em Flappy Bird para terminal
- `mario.ts` — exemplo de orientação a objetos, interfaces, herança e polimorfismo
- `tsconfig.json` — configuração do compilador TypeScript

## Como executar

### HTML
Abra `atividade.html` em um navegador.

### JavaScript com Node.js
```bash
node atividade_1.js
node atividade_2.js
node atividade_3.js
node jogo.js
node maior_idade.js
```

### TypeScript
Instale as dependências e compile os arquivos:
```bash
npm install
npm run build
```

Os arquivos compilados serão gerados na pasta `dist/`. Para iniciar os jogos após a compilação, use `npm start` (Mario) ou `npm run flappy`.
