# Exemplo de cálculo em TypeScript

Este exemplo demonstra os conceitos básicos de TypeScript: declaração de uma variável com tipo `string`, uma função tipada que soma dois números e a exibição dos resultados no terminal.

## Requisitos

- Node.js e npm instalados

## Como executar

Na raiz do repositório, instale as dependências (se ainda não tiver feito isso) e execute:

```bash
npm install
npm run calculo
```

O comando compila os arquivos TypeScript e executa o exemplo. A saída inclui uma mensagem de apresentação e o resultado de `10 + 5`.
