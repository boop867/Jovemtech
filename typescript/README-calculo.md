# Exemplo de cálculo em TypeScript

Este exemplo demonstra os conceitos básicos de TypeScript: declaração de variáveis tipadas, criação de função com parâmetros numéricos e saída no terminal.

## Requisitos

- Node.js e npm instalados

## Como executar

Na raiz do repositório:

```bash
npm install
npx tsc -p .
node .\dist\calculo.js
```

Também é possível usar:

```bash
npm run calculo
```

## Resultado esperado

O programa imprime uma mensagem inicial e o resultado da soma de `10 + 5`.
